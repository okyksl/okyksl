Fourth-year PhD candidate in the [Theory of Machine Learning Lab](https://www.epfl.ch/labs/tml/)
at EPFL, advised by [Nicolas Flammarion](https://people.epfl.ch/nicolas.flammarion).

I work on understanding learning systems from first principles: training dynamics,
generalization, and the structure of sequential data, with a focus on transformers
and autoregressive processes.

### Research codebases

Most of my experimental work lives in a few long-running project repositories:

- [hmm-attention](https://github.com/okyksl/hmm-attention) — hidden Markov models with
  hierarchical structure, attention probes, and dissection of internal computations.
- [ar-classification](https://github.com/okyksl/ar-classification) — autoregressive
  models and transformers on structured sequence classification tasks.
- [ar-transformers](https://github.com/okyksl/ar-transformers) — autoregressive
  reasoning tasks on transformers.
- [ar-linearsubspace](https://github.com/okyksl/ar-linearsubspace) — autoregressive
  linear models: stability, estimation, and sample-complexity experiments.
  Supports Long-Context Linear System Identification, ICLR 2025.

### Beyond research

Before and during my bachelor's, I was an indie game developer and released games on the
iOS App Store (RitmiSay, Tipatip), and built backend, iOS, and ML systems, first as a
freelancer and later as co-founder at [RateMe](https://www.linkedin.com/company/rateme/about/),
a computer-vision startup. The code for these projects is mostly proprietary and not listed.
Here are some public projects:

- [Actopus](https://github.com/bounswe/bounswe2018group9) — full-stack TypeScript
  activity platform, nine-person team. Top contributor, 255 commits.
- [modbus](https://github.com/okyksl/modbus) — a lightweight Modbus slave
library for Arduino, built around an abstracted communication layer so serial and
ethernet transports subclass a common core, with configurable register memory and
user-definable function codes.
